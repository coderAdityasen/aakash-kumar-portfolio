# Project Details

## Libraries and Frameworks Used

- **Three.js**: A JavaScript library for creating 3D graphics in the browser.
- **Typed.js**: A library for creating dynamic typing animations.
- **GSAP (GreenSock Animation Platform)**: A powerful library for high-performance animations.
- **Vanilla Tilt.js**: A library for creating tilt effects on elements.
- **Font Awesome**: For icons.
- **Google Fonts**: For custom fonts.

## Simple Guide to Run the Code

1. Clone the repository:
   ```bash
   git clone https://github.com/coderAdityasen/aakash-kumar-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd aakash-kumar-portfolio
   ```
3. Open `index.html` in your web browser to view the project.

4. Make sure you have an internet connection to load the external libraries from the CDN.
